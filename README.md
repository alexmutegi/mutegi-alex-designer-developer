# Mutegi Alex — Designer & Developer

Professional portfolio website for Mutegi Alex.

## Stack

- Next.js
- React
- TypeScript
- Tailwind CSS

## Sections

- Hero / personal brand
- What I Do
- Projects & Products
- Partners
- Contact

## Development

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Environment

Copy `.env.example` to `.env.local` and configure the values when integrations are added.
